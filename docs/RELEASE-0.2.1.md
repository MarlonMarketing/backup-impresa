# 0.2.1 — source backup freshness

English: Oracle downloads now check the completion time of the remote site and Docker/host backups. A successful transfer of an old archive cannot hide a failed backup schedule. Default maximum age: 30 hours, configurable from 1 to 720 hours in the task; both categories required initially. Existing file copies and repositories are preserved.

Italiano: i download Oracle controllano l’età dei backup sorgenti dei siti e di Docker/host. Il trasferimento di un archivio vecchio non nasconde una pianificazione fallita. Limite iniziale 30 ore, configurabile da 1 a 720 ore nell’attività; inizialmente sono richieste entrambe le categorie. Copie e repository esistenti conservati.

Español: las descargas Oracle comprueban la antigüedad de las copias de origen de sitios y Docker/servidor. La transferencia de un archivo antiguo no oculta una programación fallida. Límite inicial de 30 horas, configurable de 1 a 720 horas; se exigen ambas categorías inicialmente. Se mantienen las copias y repositorios existentes.
