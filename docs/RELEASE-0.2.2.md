# 0.2.2 — preserve validated Oracle sets and recognize weekly Docker copies

English: recognizes the exact daily/weekly manifest alias used by the native Oracle Docker producer. Rejects other manifest-location mismatches. A changed completion time or file identity in an already verified set now fails before overwriting its local archives. Includes source age checks from 0.2.1. No automatic deletions or repository migrations.

Italiano: riconosce il preciso alias giornaliero/settimanale dello script nativo Docker Oracle; rifiuta altre incongruenze di posizione. Se cambia la data di completamento o l'identità dei file di un gruppo già verificato, il lavoro si ferma prima di sovrascrivere gli archivi locali. Include i controlli sull'età della 0.2.1. Nessuna cancellazione automatica o migrazione di repository.

Español: reconoce el alias exacto diario/semanal del productor Docker nativo Oracle y rechaza otras discrepancias de ubicación. Si cambia la fecha o la identidad de los archivos de un conjunto ya verificado, se detiene antes de sobrescribir los archivos locales. Incluye comprobaciones de antigüedad de 0.2.1. Sin borrados automáticos ni migraciones de repositorios.
